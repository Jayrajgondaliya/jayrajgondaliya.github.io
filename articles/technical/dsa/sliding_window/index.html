Sliding Window

Understanding the Sliding Window technique with examples
April 9, 2026 · Jayraj Gondaliya

I tried solving all my problems at once… Turns out my brain only supports a fixed-size window. So now I just slide through life—one chunk at a time. 😆

Sliding Window is a subset of the Two Pointer technique.
We maintain two pointers over a sequence (array, string, etc.) to process a subset of elements efficiently.

The key idea: Instead of recalculating results for every subarray from scratch, we reuse previous computations as the window moves.

Why use Sliding Window?#

Many problems require multiple traversals of a sequence.

A brute-force approach often takes:

  • O(n²) or even O(n³)

Sliding Window reduces this to:

  • O(n) in most cases

It works by maintaining a “window” (a subarray or substring) and updating it incrementally as we iterate.

How it works#

We maintain:

  • A left pointer
  • A right pointer

These define a window over the sequence.

As we iterate:

  • Expand the window → move right
  • Shrink the window → move left
  • Update the result using only the changed elements

Types of Sliding Window#

1. Fixed Size Window#

  • Window size remains constant (e.g., size k)
  • Common in problems like maximum sum of subarray of size k

2. Variable Size Window#

  • Window expands and shrinks dynamically
  • Used in problems like:
    • Longest substring without repeating characters
    • Smallest subarray with a given sum

When to Use?#

Use Sliding Window when:

  • You are working with linear data structures:

    • Arrays
    • Strings
    • Lists

  • The problem involves:

    • Subarrays / substrings
    • Contiguous elements
    • Optimization (max / min / longest / shortest)

Common Use Cases#

  1. Subarray / substring problems
  2. Sum or average of a window
  3. Longest / shortest valid sequence
  4. Anagram detection
  5. Target sum in contiguous elements
  6. Adjacent element processing

Implementation Tips#

  • Initialize pointers carefully
  • Avoid index out-of-bounds errors
  • Handle edge cases:
    • Empty array
    • k > len(arr)
  • Avoid recomputation — reuse previous results

Example#

Find the maximum sum of any contiguous subarray of size k.

Input:
arr = [2, 5, 1, 1, 3, 2], k = 3

Optimized Approach (Sliding Window)#

Instead of recalculating the sum every time:

  • Subtract the outgoing element
  • Add the incoming element

Code#

def find_max_sum_of_subarray_size_k(arr, k):
    if len(arr) < k:
        return None

    window_sum = sum(arr[:k])
    max_sum = window_sum

    for right in range(k, len(arr)):
        window_sum += arr[right]          # add incoming element
        window_sum -= arr[right - k]      # remove outgoing element
        max_sum = max(max_sum, window_sum)

    return max_sum
